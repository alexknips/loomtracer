# Portable v5 package 1.0.0

This additive export provides the maintained-notes calibration harness without private development artifacts or dependency on the original workspace layout.

| Identifier | Version |
| --- | --- |
| Corpus | `functionality-v5-corpus-1.0.2` |
| Protocol | `functionality-v5-isolated-workflows-1.1.1` |
| Strict-units scoring implementation | `functionality-v5-strict-units-1.0.1` |
| Report | `functionality-v5-report-1.0.2` |

- Release sources now explicitly establish Priya's producer role. Source-grounding checks reject absent, negated, ambiguous, quoted, wrong-actor, wrong-scope, future, and noise-only substitutions.
- The Q catch-all guard excludes fields with dedicated scoring obligations, avoiding two penalties for the same request. Strict criteria and denominators are retained.
- D reports preserve a semantic late-recognition finding even when the deterministic timing flag is false. This fixes display consistency without making late answers pass.
- Offline validation and dependency installation work from this standalone folder. Validation emits a pending source-bound review template rather than treating passing tests as semantic approval.
- Live preparation requires new operator authorization and a reviewed frozen implementation. No prior budget permission is carried into this export.
- Historical continuation exceptions, stale planning JSON, private run paths, and saved output/usage records are excluded. The export does not rescore or rerun original workflows.

`provenance/source-snapshot.json` identifies the local upstream source revision by file hashes. It describes origin; validation snapshots identify the exact repaired files used for a new test.
